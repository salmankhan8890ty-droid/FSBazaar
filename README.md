# FS Bazaar — Android starter

Brand: Navy `#0D47A1`, Orange `#FF6B00`, White `#FFFFFF`
Tagline: Sab Kuch, Ek Hi Jagah!

This is a starter Android project for the FS Bazaar marketplace. It currently provides a basic home screen and category shortcuts. It is **not yet a production marketplace**: login, database, payments, seller onboarding, order notifications, courier APIs, and admin controls still need backend integration and testing.

## Open/build
1. Open this project in Android Studio.
2. Let Gradle sync complete.
3. Run the `app` configuration on an emulator or Android device.
4. To create an APK, use **Build > Build APK(s)**.

## Next development stages
1. Backend and authentication (customer, seller, admin roles)
2. Product catalog and search
3. Cart, checkout, order creation
4. Seller dashboard and inventory
5. Admin moderation and reporting
6. Courier integration and tracking
7. Payment provider integration and security review

Never put API keys, passwords, or payment secrets in the app source code.
